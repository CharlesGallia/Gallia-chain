# Gallia — la chaîne du Gallo

La chaîne de la Gallia et sa monnaie, le **Gallo**, inspirée de la Ğ1 et construite à partir du logiciel libre Duniter v2.

- **Le pain quotidien** : chaque Galli vérifié reçoit chaque matin sa part, la même pour tous.
- **La Gallibra** : la création monétaire de la Banque de la Gallia, qui crée les Gallo.
- **Le mérite** : des Gallo en plus pour l'entraide, le savoir et les projets de la Vota Publica.

Le code est public pour que chacun puisse le relire. La mission de construction est décrite dans `CLAUDE.md`.

*Le pain pour tous, le mérite pour chacun.*
